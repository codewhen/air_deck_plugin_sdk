## Requirements

Install AirDeck Helper on the desktop you will test against and the AirDeck Android app on your phone. Pair them over your trusted local network. Plugin development and initial protocol checks do not require a connected phone.

Choose a toolchain:

| Language | Build tools | User's computer |
| --- | --- | --- |
| Go | Go version from `deck-plugins/go.mod` | Native executable; no Go installation |
| Python | Python 3.10+ | Python 3.10+ on PATH |
| Java | JDK 17+, Gson JAR | Java 17+ on PATH |
| C++ | C++17 compiler | Native executable and applicable system runtime |

Python 3.11+ is recommended for the SDK's tooling. Windows Python/Java launchers also need Go **at build time**, not on the user's computer. The C++ build script uses `c++`; on Windows use a MinGW C++ toolchain or set `CXX` to its `g++` executable.

## Clone the SDK

```sh
git clone https://github.com/codewhen/air_deck_plugin_sdk.git
cd air_deck_plugin_sdk
```

The important folders are `deck-plugins/sdk`, `deck-plugins/plugins/examples`, `capabilities/schemas`, and `tools`. Clone the public repository only; the private app source is not needed.

## Choose your tutorial

Follow [Go](./go), [Python](./python), [Java](./java) or [C++](./cpp). Commands run from the SDK repository root unless a step explicitly changes directories.

On Windows, run the Python tooling with `python` instead of `python3`. Put Java and Python on PATH when those runtimes are required. The packaging script selects a native Windows executable launcher automatically for Python and Java.

## Verify the package protocol

After building, run:

```sh
python3 tools/test_packaged_examples.py deck-plugins/dist/examples/go/com.example.echo.deckPlugin
```

Replace `go` with your language. This extracts the package to a temporary directory and checks catalog, successful invoke, and failed invoke correlation. The successful invoke plays a brief sound. Real phone/desktop testing is still required before distribution.

## Test on your phone

In AirDeck Helper, open **Plugins**, install the package and review any requested permissions. On your phone, open the Stream Deck editor, find the plugin action in the library, add it to a layout, save and tap it. See [testing](./testing) for the release checklist.
