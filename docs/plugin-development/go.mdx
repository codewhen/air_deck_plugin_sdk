## What you will build

Echo Beep exposes one button in the phone's Stream Deck library. The helper sends its `beep` action to your desktop plugin. The source is in `deck-plugins/plugins/examples/go`.

[View the complete go example on GitHub](https://github.com/codewhen/air_deck_plugin_sdk/blob/main/deck-plugins/plugins/examples/go/main.go).

## Prepare the toolchain

Install Go, then [clone the SDK](./getting-started). Run commands below from the SDK root. On Windows, use `python` in place of `python3`.

## Read the implementation

Implement `Catalog() []decksdk.Button` and `Invoke(typ, action string, body, payload json.RawMessage) error`, then run `decksdk.Run(&plugin{})`.

```go
func (p *plugin) Catalog() []decksdk.Button {
    return []decksdk.Button{{ID: "echo.beep", Title: "Echo Beep",
        Action: "beep", PluginID: "com.example.echo", Columns: 1, Rows: 1}}
}
func main() { decksdk.Run(&plugin{}) }
```

The complete `main.go` handles unknown actions and plays a platform-appropriate sound. SDK imports use the public Go module path `github.com/codewhen/air_deck_plugin_sdk/deck-plugins/sdk/go/decksdk`.

## Build and package

```sh
python3 tools/build_examples.py go
```

The package is `deck-plugins/dist/examples/go/com.example.echo.deckPlugin`.

## Test and install

```sh
python3 tools/test_packaged_examples.py deck-plugins/dist/examples/go/com.example.echo.deckPlugin
```

Install the package through AirDeck Helper → Plugins. Add Echo Beep on the phone, save the layout and tap it. Other language tutorials share the same plugin ID; install only one Echo implementation at a time.

## Make it your own

Copy the template inside `deck-plugins/plugins`, change its manifest ID/name and the plugin ID reported by the implementation, then edit the action logic. Keep the template filenames and class name for this builder.

```sh
python3 -c "import shutil; shutil.copytree('deck-plugins/plugins/examples/go', 'deck-plugins/plugins/my-plugin')"
python3 tools/build_examples.py go --plugin-dir deck-plugins/plugins/my-plugin
```

The builder reads your manifest ID to name the package. Use a stable namespace you control, and update the catalog's plugin ID to match. Declare broker permissions before adding [core capability calls](./capabilities). See [distribution](./distribution) for other package layouts.

## Platform status

The example build, extracted catalog and invoke checks are verified on macOS. Windows commands and native launchers are included but require an actual Windows helper test before claiming Windows support.
