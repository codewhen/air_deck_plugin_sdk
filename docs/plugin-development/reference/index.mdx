## Terms used throughout the guide

| Term | Meaning |
| --- | --- |
| SDK | Public libraries and tools used by your plugin |
| Plugin | Your executable implementation and its declared actions |
| Helper / host | AirDeck's computer-side application that starts plugins and routes commands |
| Catalog | The list of actions/buttons your plugin offers |
| Invocation | One request to perform a particular action |
| Capability | A versioned service exposed by the helper or a provider plugin |
| Permission | A grant required to use a broker operation or topic |
| Package | A `.deckPlugin` archive containing installation/runtime files |

This reference covers API v2. A successful protocol response means the handler completed successfully; it is not a guarantee that every external application supports the requested operation.
