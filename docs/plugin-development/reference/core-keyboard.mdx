## Before calling this capability

Declare the permissions needed by your selected methods/topics and a compatible `uses` range for `core.keyboard`. Construct the generated client from the SDK host during initialization. Handle denied permissions, incompatible contracts and operational failures.

The current core key-press implementation accepts the lowercase keys `up`, `down`, `left`, `right` and `enter`. The string schema is not a promise that every possible key name is supported. Unsupported names return `invalid_arguments`.

Use `hotkey` for a supported combination and test its platform-specific parsing and effect. Avoid leaving keys pressed or assuming a keyboard layout is identical on every machine.
