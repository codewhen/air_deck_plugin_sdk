## Before calling this capability

Declare the permissions needed by your selected methods/topics and a compatible `uses` range for `core.media`. Construct the generated client from the SDK host during initialization. Handle denied permissions, incompatible contracts and operational failures.

Playback/track availability depends on the operating system and media application. Inspect `available`; an unknown or unavailable snapshot is not a playing/paused guarantee. A successful next/previous command does not prove the prepared player has another track.

Volume and mute are separate values. Use `setMute` for mute state rather than assuming a zero volume is equivalent. Respect the numeric ranges below. Subscribe to playback/track/volume topics when a UI needs current state.
