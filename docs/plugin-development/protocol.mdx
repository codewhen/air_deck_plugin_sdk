## The process contract

AirDeck Helper starts the plugin and exchanges one JSON object per line over stdin/stdout. API v2 requests and replies use `ipc_id` for correlation. Write diagnostic logs to **stderr** only. Avoid stdout prints from subprocesses too.

```json
{"op":"catalog","ipc_id":"catalog-1"}
{"op":"ok","ipc_id":"catalog-1","buttons":[{"id":"echo.beep","title":"Echo Beep","action":"beep","plugin_id":"com.example.echo","columns":1,"rows":1}]}
```

An invocation includes its type, action, body and payload:

```json
{"op":"invoke","ipc_id":"invoke-1","type":"plugin.command","action":"beep","body":{},"payload":{}}
{"op":"ok","ipc_id":"invoke-1"}
```

Use the SDK rather than implementing framing and concurrency yourself.

## Lifecycle and button catalog

Implement catalog and invoke, then run the SDK host loop. Go plugins may implement `Init(*decksdk.Host)`; Python uses `init(host)`; Java uses `PluginHost.Initializer`; C++ overrides `init(Host&)`.

Buttons have a stable ID, user-facing title, action and plugin ID. The examples use `icon_key: "plugins"`, one column and one row. Editor flags indicate tap/toggle support. Optional polling can return button states where supported by the SDK.

## Capability traffic

The SDK can issue `capability.call`, `capability.subscribe`, `capability.publish` and cancellation/unsubscribe messages while processing a host request. The reader must continue running so calls receive replies. Use generated clients and SDK methods for this behavior.

## Errors and timeouts

A failed request returns `op: "error"`, a matching `ipc_id`, and an error message; SDK capability errors preserve structured codes. Distinguish denied permissions, unavailable capabilities, invalid arguments and operational failures. Do not retry destructive operations blindly after a timeout.

```json
{"op":"error","ipc_id":"invoke-1","code":"permission_denied","error":"Not granted"}
```

Design actions to finish promptly and honor cancellation where the language API supplies it. Close subscriptions and resources on shutdown. Do not depend on final cleanup after a crash or forced termination.
