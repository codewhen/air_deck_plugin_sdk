## What you will build

Echo Beep exposes one button in the phone's Stream Deck library. The helper sends its `beep` action to your desktop plugin. The source is in `deck-plugins/plugins/examples/python`.

## Prepare the toolchain

Install Python 3.10+, then [clone the SDK](./getting-started). Run commands below from the SDK root. On Windows, use `python` in place of `python3`.

## Read the implementation

Subclass `DeckPlugin`, return button dictionaries from `catalog`, implement `invoke`, and call `run(EchoPlugin())`.

```python
from decksdk import DeckPlugin, run

class EchoPlugin(DeckPlugin):
    def catalog(self):
        return [{"id": "echo.beep", "title": "Echo Beep",
                 "action": "beep", "plugin_id": "com.example.echo",
                 "columns": 1, "rows": 1}]
    def invoke(self, typ, action, body, payload):
        if action != "beep":
            raise ValueError("Unknown action")
        print("Button tapped", file=__import__("sys").stderr)

run(EchoPlugin())
```

The complete template uses a local packaged `sdk` directory and plays a platform-appropriate sound. The snippet illustrates the interface; keep the template's import setup when packaging.

## Build and package

```sh
python3 tools/build_examples.py python
```

The package is `deck-plugins/dist/examples/python/com.example.echo.deckPlugin`.

The package includes the Python SDK files, but users still need Python 3.10+ on PATH. Windows packaging also needs Go to build a native launcher; users do not need Go.

## Test and install

```sh
python3 tools/test_packaged_examples.py deck-plugins/dist/examples/python/com.example.echo.deckPlugin
```

Install the package through AirDeck Helper → Plugins. Add Echo Beep on the phone, save the layout and tap it. Other language tutorials share the same plugin ID; install only one Echo implementation at a time.

## Make it your own

Copy the template inside `deck-plugins/plugins`, change its manifest ID/name and the plugin ID reported by the implementation, then edit the action logic. Keep the template filenames and class name for this builder.

```sh
python3 -c "import shutil; shutil.copytree('deck-plugins/plugins/examples/python', 'deck-plugins/plugins/my-plugin')"
python3 tools/build_examples.py python --plugin-dir deck-plugins/plugins/my-plugin
```

The builder reads your manifest ID to name the package. Use a stable namespace you control, and update the catalog's plugin ID to match. Declare broker permissions before adding [core capability calls](./capabilities). See [distribution](./distribution) for other package layouts.

## Platform status

The example build, extracted catalog and invoke checks are verified on macOS. Windows commands and native launchers are included but require an actual Windows helper test before claiming Windows support.
